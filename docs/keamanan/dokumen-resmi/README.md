# Dokumen resmi keamanan & privasi

Versi formal yang siap ditandatangani, disusun dari draf G4 (`docs/tim/hasil-gpt/G4/`). Ketentuan isian:
- Isi semua `[ISI]`, `[NAMA]`, dan `[TANGGAL]`, lalu cetak atau ekspor ke PDF dan tanda tangani. Gunakan meterai untuk NDA.
- Unggah PDF bertanda tangan sebagai bukti di matriks Security Self-Assessment SATUSEHAT.
- Sebaiknya ditinjau advokat sebelum disahkan, terutama dokumen 02 dan 03.

| No | Dokumen | Untuk |
|---|---|---|
| 01 | Kebijakan Keamanan Informasi (induk) | SATUSEHAT: kebijakan keamanan; PSE |
| 02 | Kebijakan Pelindungan Data Pribadi | UU PDP, SATUSEHAT |
| 03 | Templat NDA | Setiap karyawan/kontraktor/vendor yang mengakses data |
| 04 | SK Penunjukan DPO & PIC Keamanan | UU PDP Pasal 53; narahubung SATUSEHAT/PSE |
| 05 | SOP Pemisahan Lingkungan & Data | SATUSEHAT: pemisahan environment |
| 06 | Laporan Uji DR 11 Okt 2026 | SATUSEHAT: bukti uji pemulihan |
