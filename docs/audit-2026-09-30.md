## B. Rencana pengembangan (lebih profesional)

### Fase 0 — Perbaikan kritis (1–3 hari)
1. Pricing crash (#2), organization/procedure SATUSEHAT (#3, #4), cek klinik di `send-whatsapp` (#14).
2. Cron pengingat WA + versi multi-tenant (#6, #15); provider WA mengikuti pengaturan (#9).
3. Perbaiki/ganti `whatsapp-webhook` (#16) dan masukkan ke repo.
4. Matikan Legacy API keys (#19); hapus `backup_20260929` (#18).
5. **CI: uji boot semua Edge Function + `deno check`** sebelum deploy (#28).

### Fase 1 — Fondasi andal (2–4 minggu)
- **Tes**: unit service (pasien, kunjungan, pembayaran, enkripsi), e2e alur inti (daftar pasien → kunjungan → resep → bayar → kwitansi), kontrak payload SATUSEHAT. Target ≥ 60 % service layer.
- **Database**: konsolidasi RLS (1 policy per aksi per tabel), indeks FK, hapus tabel warisan, satukan `master_obat`/`master_bahan`.
- **Operasional**: SMTP sendiri (Resend), Sentry (klinik + Console + Edge), alert cron gagal, upgrade Supabase Pro (backup harian + PITR, leaked-password protection), domain `dentiva.co.id`/`.id`.
- **SATUSEHAT**: kredensial sandbox → jalankan `satusehat-sandbox-verify` → kredensial per klinik (Vault) → buka produksi.

### Fase 2 — Fitur yang dijual (1–2 bulan)
- **Riwayat versi RME** di halaman kunjungan (pasang `EMRHistory` + restore dengan alasan).
- **Kasir QRIS** untuk pasien (Midtrans/Xendit dynamic QRIS) + kwitansi digital WA.
- **Booking online pasien** (halaman publik per klinik + slot dari jadwal dokter + konfirmasi WA).
- **Mode offline nyata** untuk pendaftaran & SOAP (antrian IndexedDB + sinkron) — atau diwujudkan lewat aplikasi desktop (bagian C).
- Onboarding: templat tarif/tindakan standar PDGI, impor pasien dari Excel.
- Portal pasien sederhana (riwayat kunjungan, resep, jadwal kontrol).

### Fase 3 — Skala (3–6 bulan)
- **Multi-cabang** (organisasi → banyak klinik, laporan gabungan) — prasyarat klaim paket Enterprise.
- Laporan manajemen (retensi pasien, produktivitas dokter, HPP per tindakan), ekspor pajak.
- Integrasi BPJS (P-Care/VClaim) bila menyasar klinik mitra BPJS.
- Kepatuhan: pendaftaran PSE Kominfo, DPO & kebijakan UU PDP, uji penetrasi eksternal, menuju ISO 27001.

## C. Rencana aplikasi desktop Windows & macOS (satu file installer)

### Rekomendasi: **Tauri 2**
| | Tauri 2 (disarankan) | Electron |
|---|---|---|
| Ukuran installer | ± 5–15 MB | ± 80–150 MB |
| RAM | rendah (WebView bawaan OS) | tinggi (Chromium sendiri) |
| Installer | Windows `.msi` / `.exe` (NSIS), macOS `.dmg` | sama |
| Auto-update | plugin updater bawaan (bertanda tangan) | electron-updater |
| Akses printer/berkas | plugin resmi | Node penuh |

Aplikasi klinik sudah React + Vite dan sudah PWA, sehingga bisa dibungkus tanpa menulis ulang.

### Arsitektur
- Folder baru `apps/desktop` (Tauri) memakai build `apps/clinic` yang sama.
- **Mode 1 — online (rilis pertama):** jendela memuat aplikasi yang dibundel di dalam installer, data tetap ke Supabase. Pembaruan UI lewat auto-update.
- **Mode 2 — offline-first (rilis berikutnya):** cache SQLite lokal terenkripsi untuk pasien & jadwal hari ini, antrian tulis saat internet putus, sinkron saat online.
- Fitur khusus desktop: cetak kwitansi/resep langsung ke printer thermal (tanpa dialog), jendela kedua untuk **layar antrean di monitor/TV kedua**, mulai otomatis saat komputer menyala, notifikasi sistem, pintasan keyboard kasir.

### Distribusi & keamanan
- **Tanda tangan kode wajib**, supaya tidak diblokir Windows SmartScreen / macOS Gatekeeper:
  - Windows: sertifikat OV/EV code-signing atau Azure Trusted Signing (± USD 10/bulan).
  - macOS: Apple Developer Program (USD 99/tahun) + notarization.
- **Build otomatis** di GitHub Actions (runner Windows + macOS) → rilis di GitHub Releases → updater membaca `latest.json` bertanda tangan.
- Unduhan dari halaman `dentiva.co.id/download`; macOS dibuat *universal* (Intel + Apple Silicon).
- CSP & izin Tauri dibatasi ke domain Supabase/Vercel; sesi login disimpan di keychain OS, bukan file biasa.

### Tahapan
| Minggu | Pekerjaan | Hasil |
|---|---|---|
| 1 | Setup Tauri + build Windows/macOS lokal, ikon & branding | Installer uji tanpa tanda tangan |
| 2 | Cetak thermal, jendela layar antrean, auto-start | Fitur desktop inti |
| 3 | Sertifikat + CI GitHub Actions + auto-update | Installer bertanda tangan, update otomatis |
| 4 | Uji di 3–5 komputer klinik (Win 10/11, macOS 13+), halaman unduh | Rilis 1.0 desktop |
| 5–8 | Mode offline-first (SQLite + sinkron) | Rilis 1.1 |
