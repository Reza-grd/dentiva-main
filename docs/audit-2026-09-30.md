## C. Rencana aplikasi desktop Windows & macOS (satu file installer)

### Rekomendasi: **Tauri 2**
| | Tauri 2 (disarankan) | Electron |
|---|---|---|
| Ukuran installer | ± 5–15 MB | ± 80–150 MB |
| RAM | rendah (WebView bawaan OS) | tinggi (Chromium sendiri) |
| Installer | Windows `.msi` / `.exe` (NSIS), macOS `.dmg` | sama |
| Auto-update | plugin updater bawaan (bertanda tangan) | electron-updater |
| Akses printer/berkas | plugin resmi | Node penuh |

Aplikasi klinik sudah React + Vite dan sudah PWA, sehingga bisa dibungkus tanpa menulis ulang.

### Arsitektur
- Folder baru `apps/desktop` (Tauri) memakai build `apps/clinic` yang sama.
- **Mode 1 — online (rilis pertama):** jendela memuat aplikasi yang dibundel di dalam installer, data tetap ke Supabase. Pembaruan UI lewat auto-update.
- **Mode 2 — offline-first (rilis berikutnya):** cache SQLite lokal terenkripsi untuk pasien & jadwal hari ini, antrian tulis saat internet putus, sinkron saat online.
- Fitur khusus desktop: cetak kwitansi/resep langsung ke printer thermal (tanpa dialog), jendela kedua untuk **layar antrean di monitor/TV kedua**, mulai otomatis saat komputer menyala, notifikasi sistem, pintasan keyboard kasir.

### Distribusi & keamanan
- **Tanda tangan kode wajib**, supaya tidak diblokir Windows SmartScreen / macOS Gatekeeper:
  - Windows: sertifikat OV/EV code-signing atau Azure Trusted Signing (± USD 10/bulan).
  - macOS: Apple Developer Program (USD 99/tahun) + notarization.
- **Build otomatis** di GitHub Actions (runner Windows + macOS) → rilis di GitHub Releases → updater membaca `latest.json` bertanda tangan.
- Unduhan dari halaman `dentiva.co.id/download`; macOS dibuat *universal* (Intel + Apple Silicon).
- CSP & izin Tauri dibatasi ke domain Supabase/Vercel; sesi login disimpan di keychain OS, bukan file biasa.

### Tahapan
| Minggu | Pekerjaan | Hasil |
|---|---|---|
| 1 | Setup Tauri + build Windows/macOS lokal, ikon & branding | Installer uji tanpa tanda tangan |
| 2 | Cetak thermal, jendela layar antrean, auto-start | Fitur desktop inti |
| 3 | Sertifikat + CI GitHub Actions + auto-update | Installer bertanda tangan, update otomatis |
| 4 | Uji di 3–5 komputer klinik (Win 10/11, macOS 13+), halaman unduh | Rilis 1.0 desktop |
| 5–8 | Mode offline-first (SQLite + sinkron) | Rilis 1.1 |

Prasyarat dari pemilik: akun Apple Developer, sertifikat Windows code-signing, domain unduhan.
