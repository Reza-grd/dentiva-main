# Menjaga privasi pasien dan meminta bantuan pemulihan

**Untuk siapa:** admin, dokter, resepsionis/kasir.

Gunakan informasi pasien hanya untuk pekerjaan yang diizinkan. Hubungi admin klinik jika membutuhkan bantuan akses atau pemulihan data.

## Langkah

1. Periksa peran pada **Menu profil pengguna**. Gunakan menu sesuai tugas: admin untuk bisnis/agregat, dokter untuk klinis, resepsionis untuk administrasi serta pembayaran. Jika **Akses Ditolak**, pilih **Kembali ke Dashboard** dan hubungi admin klinik bila hak akses perlu ditinjau.
2. Saat mencari atau membuka detail pasien, verifikasi penerima dan tujuan penggunaan sebelum menyalin, mencetak, atau membagikan informasi. Jangan masukkan data pasien ke Eira; gunakan panduan tanpa identitas.
3. Jika pasien meminta salinan, koreksi, atau penghapusan, teruskan ke penanggung jawab klinik melalui admin. Dokter/resepsionis berwenang dapat membuka detail pasien dan **Catat Permintaan** sesuai prosedur verifikasi klinik. Mencatat permintaan tidak otomatis mengabulkan atau menghapus data.
4. Untuk bantuan cadangan atau pemulihan data, lihat [petunjuk pada status layanan](status-layanan.md#pemulihan-data).
5. Akhiri sesi melalui **Menu profil pengguna → Keluar** ketika selesai, terutama pada perangkat bersama. Amankan hasil cetak dan unduhan sebelum menyerahkan perangkat.

## Catatan keamanan

- Jangan mengirim salinan cadangan, PDF pasien, tautan layar TV, atau tangkapan layar yang berisi data pasien ke layanan AI/kanal dukungan umum.
- Jika menduga informasi terlihat oleh pihak yang salah, hentikan pembagian dan segera hubungi admin klinik melalui kanal resmi tanpa meneruskan data sensitifnya.
