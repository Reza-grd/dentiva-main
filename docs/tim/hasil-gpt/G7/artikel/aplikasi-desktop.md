# Menggunakan Dentiva Desktop dan menangani pembaruan

**Untuk siapa:** admin, dokter, resepsionis/kasir.

Dentiva Desktop menampilkan aplikasi klinik dalam jendela desktop. Gunakan koneksi internet saat membuka data dan menyimpan pekerjaan.

## Langkah

1. Pada halaman masuk versi web, pilih **Unduh aplikasi desktop**. Minta admin klinik memverifikasi sumber dan installer resmi sebelum pemasangan Windows/macOS; bila perangkat menampilkan peringatan keamanan, hentikan dan minta bantuan admin.
2. Setelah pemasangan yang disetujui pengelola, buka Dentiva dan masuk dengan akun pribadi melalui **Masuk ke Sistem**. Periksa peran seperti pada aplikasi web.
3. Jika kartu **Dentiva … tersedia** muncul, simpan semua pekerjaan dahulu. Pilih **Perbarui sekarang** untuk memasang pembaruan, atau **Nanti** untuk melanjutkan pekerjaan.
4. Tunggu proses unduh, pemasangan, dan mulai ulang. Jika kartu menampilkan kegagalan, periksa koneksi dan gunakan **Coba lagi** hanya setelah pekerjaan aman; bila tetap gagal, hubungi admin klinik untuk installer yang diverifikasi.
5. Untuk mencetak invoice, buka **Pembayaran → Detail → Cetak Invoice**; lihat [bantuan pencetakan desktop](status-layanan.md#desktop-cetak) bila dialog cetak tidak muncul.

## Catatan keamanan

- Jangan mematikan SmartScreen, Gatekeeper, antivirus, atau pemeriksaan tanda tangan untuk memasang aplikasi.
- Saat koneksi terputus, periksa kembali hasil penyimpanan setelah jaringan pulih sebelum mengulang transaksi.

Lihat status layanan untuk [pembaruan desktop](status-layanan.md#desktop-pembaruan).
