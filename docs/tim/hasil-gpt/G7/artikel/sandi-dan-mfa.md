# Mengganti sandi, lupa sandi, dan status MFA

**Untuk siapa:** admin, dokter, resepsionis/kasir.

Anda dapat mengganti sandi ketika masih bisa masuk. Gunakan sandi panjang dan unik untuk akun Anda.

## Langkah

1. Jika masih bisa masuk, buka **Menu profil pengguna → Pengaturan → Keamanan**.
2. Isi **Password saat ini**, **Password baru**, dan **Konfirmasi password baru**. Ikuti petunjuk aplikasi bila sandi baru belum diterima.
3. Pilih **Update Password** dan tunggu pesan **Password berhasil diganti!**. Bila gagal, jangan menganggap sandi sudah berubah.
4. Untuk MFA, lihat [petunjuk pada status layanan](status-layanan.md#mfa-mandiri).
5. Jika lupa sandi atau tidak bisa masuk, lihat [bantuan pengaturan ulang sandi](status-layanan.md#email-reset).

## Catatan keamanan

- Hubungi admin klinik melalui kontak yang sudah Anda kenal saat membutuhkan bantuan akses.
- Dukungan tidak memerlukan sandi lama, QR MFA, maupun kode sekali pakai Anda. Jangan menonaktifkan perlindungan perangkat sebagai jalan pintas.
