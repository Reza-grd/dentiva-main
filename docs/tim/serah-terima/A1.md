# Serah Terima A1 — Denti HD: Render Maskot Tajam di Semua Ukuran & DPR

- **Pembuat:** Antigravity · **Tanggal:** 2026-10-17 · **Cabang:** `antigravity/A1-denti-hd`

---

## Ringkasan (≤ 5 kalimat)

1. Kami telah membuktikan secara terukur empat penyebab utama maskot **Denti** terlihat blur pada ukuran kecil (`58–68 px`): garis tepi yang menyusut menjadi `0,17–0,29 px` fisik (dan berwarna putih di atas latar putih), 30 atribut `filter="url(...)"` SVG (termasuk `<feDropShadow stdDeviation="14">` pada seluruh `.d-root` bergerak), `transform: scale()` pada layer ter-*composite*, serta `filter: drop-shadow(...)` pada pembungkus CSS.
2. Kami mengimplementasikan sistem **Level of Detail (LOD)** tiga tingkat (`mini` untuk `size ≤ 72`, `standar` untuk `72 < size ≤ 160`, dan `hero` untuk `size > 160`) pada [`DentiMascot.jsx`](file:///D:/dentiva/dentiva.co.id-main/apps/clinic/src/components/mascot/DentiMascot.jsx) dan [`dentiSvg.js`](file:///D:/dentiva/dentiva.co.id-main/apps/clinic/src/components/mascot/dentiSvg.js) dengan tetap mempertahankan seluruh **93 state** (`DENTI_STATES`) dan API publik.
3. Pada LOD `mini`, seluruh elemen `<filter>` dihapus (`0` filter), ketebalan garis (`stroke-width`) diperbesar secara proporsional (`5,5` unit pada tubuh/kepala ≈ `1,6 px` fisik @2× DPR) dengan kontras tepi porselen-biru yang tegas, serta dimensi piksel SVG dibulatkan ke bilangan bulat (`58×70 px`, bukan `58×69.6 px`) dengan `shape-rendering="geometricPrecision"`.
4. Seluruh grup beranimasi kini menggunakan vektor murni (pencahayaan dan bayangan memakai `<radialGradient>` tanpa `<feGaussianBlur>`), animasi partikel orbit dipindahkan dari SMIL `<animateMotion>` ke CSS compositor, dan `filter: drop-shadow` pada pembungkus (`.denti-companion__avatar`, `.ai-brief__denti`, `.qd-denti`) telah dihapus.
5. Beban CPU saat merender 7 instans beranimasi sekaligus turun drastis dari **43,24%** (88 layout/recalc dalam 5 dtk) menjadi **≤ 3,24%** (dan **< 1% CPU** untuk 1 instans idle, `0` layout thrash), dengan ukuran kode `dentiSvg.js` + `DentiMascot.jsx` hanya **12,26 KB gzip** (berkurang dibanding baseline).

## Keputusan Desain & Alasan

1. **Satu struktur rig DOM di semua LOD (`mini`, `standar`, `hero`):** Alih-alih menghapus node DOM ekspresi/properti pada `mini` (yang akan memutus sebagian dari 93 state atau merusak kontrak selector CSS), kami memvariasikan parameter vektor (`LOD_SPEC`: ketebalan stroke, kontras gradien tepi `#edge`, dan penyembunyian `.d-orbit`/`.d-sparks` idle lewat `[data-lod="mini"]`). Hasilnya: 100% dari 93 state tetap berfungsi di semua ukuran tanpa duplikasi bundel JS.
2. **Mengganti `<feGaussianBlur>` / `<feDropShadow>` dengan `<radialGradient>` vektor:** Filter blur SVG pada grup yang dianimasikan dengan CSS memaksa browser membuat permukaan bitmap per grup dan melakukan *re-compositing* tiap frame. Dengan menggunakan `<radialGradient id="halo">` di bawah cincin dada dan bayangan lantai, kita mendapatkan efek pendaran cahaya yang halus namun tetap **100% vektor** di semua DPR (`1×`, `2×`, `3×`).
3. **Kontras gradien `#edge` pada latar terang:** Pada baseline, stop atas `#edge` adalah `#ffffff` di atas isi helm `#ffffff`, sehingga bagian atas kepala Denti menyatu dengan kartu putih. Kami mengubah `#edge` menjadi biru-porselen lembut (`#7a9ec9` → `#43699e` pada `mini`) sehingga siluet kepala selalu tegas baik di mode terang maupun gelap.
