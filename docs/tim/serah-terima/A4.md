## 1. Ringkasan Eksekutif

Paket **A4** membangun infrastruktur pengujian mutu otomatis ujung-ke-ujung (*end-to-end*), regresi visual, audit aksesibilitas (`axe-core` WCAG 2.1 AA), dan anggaran performa/praktik terbaik (`Lighthouse CI`) pada `apps/clinic` yang berjalan sepenuhnya di atas **data klinik sintetis lokal** tanpa pernah menyentuh server produksi maupun kunci rahasia.

Selain membangun rangkaian uji otomatis, eksekusi pertama Playwright dan `axe-core` berhasil menemukan dan memperbaiki **3 bug runtime nyata** serta **7 kelompok pelanggaran aksesibilitas (`serious`/`critical`)** pada komponen aplikasi klinik.

### B. Perbaikan Bug Runtime & Aksesibilitas yang Ditemukan oleh E2E + `axe-core`
1. **Bug Runtime 1 — `apps/clinic/src/components/payment/PaymentList.jsx`:**
   - **Masalah:** Menggunakan `<FileText />` pada kartu ringkasan transaksi (baris 170) tanpa mengimpor `FileText` dari `lucide-react`, menyebabkan halaman `/resepsionis/pembayaran` crash (`ReferenceError: FileText is not defined`) dan masuk ke `ErrorBoundary`.
   - **Perbaikan:** Menambahkan `FileText` ke impor `lucide-react` serta menambahkan `aria-label` pada input pencarian dan `<select>` filter pembayaran.
2. **Bug Runtime 2 — `apps/clinic/src/components/schedule/SchedulePage.jsx`:**
   - **Masalah:** Mengimpor `useToast` tetapi tidak mendeklarasikan `const toast = useToast();` di dalam komponen `SchedulePage`, sehingga penyimpanan jadwal baru melempar `ReferenceError: toast is not defined` sebelum modal ditutup.
   - **Perbaikan:** Menambahkan `const toast = useToast();` serta memperbaiki `aria-label` pada input tanggal/select filter dan kontras warna teks kalender mingguan & slot praktek.
3. **Bug Runtime 3 — `apps/clinic/src/components/auth/LoginPage.jsx`:**
   - **Masalah:** Saat `signIn` gagal, `AuthContext` mengubah `loading` menjadi `true` → `false` yang meng-unmount `<LoginPage />` di `App.jsx` (`if (loading) return <LoadingSpinner fullScreen />`), sehingga state lokal `serverError` di `LoginPage` hilang saat komponen di-mount ulang.
   - **Perbaikan:** Membaca `error: authError` dari `useAuth()` (`const displayError = serverError || authError`) dan menambahkan `aria-label` pada tombol tampilkan/sembunyikan password.
4. **Perbaikan Aksesibilitas (`color-contrast` & `select-name`) Lainnya:**
   - `apps/clinic/src/components/layout/TopBar.jsx`: Meningkatkan kontras teks breadcrumb `Dentiva` dan badge peran (`admin`, `resepsionis`, `dokter`) agar memenuhi rasio kontras WCAG AA ≥ 4.5:1.
   - `apps/clinic/src/components/dashboard/AdminDashboard.jsx`: Meningkatkan kontras subtitle kartu grafik (`text-gray-600 dark:text-gray-400`) dan `StatusBadge`.
   - `apps/clinic/src/components/common/PatientAvatar.jsx` & `apps/clinic/src/components/patient/PatientList.jsx`: Meningkatkan kontras teks inisial avatar perempuan/laki-laki dan menambahkan `aria-label` pada 3 elemen `<select>` filter/paginasi.
   - `apps/clinic/src/components/ai/AiAssistantPage.jsx`: Meningkatkan kontras badge `Beta` dan judul kelompok saran pertanyaan.
