## Risiko, batasan, dan hal yang belum selesai

- Ini konten siap ditinjau, bukan integrasi halaman pusat bantuan. Belum ada rute, mesin pencarian, penilaian artikel, atau distribusi pengguna yang dipasang.
- Rujukan nomor baris berlaku untuk snapshot yang tercatat. Jika komponen berubah, baca ulang langkah sebelum memperbarui bukti.
- Kesiapan layanan server, konfigurasi per klinik/paket, pengiriman WA, email, installer, dan pemulihan cadangan tidak diuji. Pengguna diminta mengikuti hasil aktual dan admin klinik.
- Uji klik runtime, perangkat desktop/ponsel, axe, dan tinjauan akhir penanggung jawab klinik sebelum publikasi masih diperlukan. Validator tidak membuktikan hak akses server atau keselamatan klinis.

### Temuan lain

- Aktivasi MFA klinik masih tombol nonaktif; enrollment dan pemaksaan MFA tidak dijanjikan.
- Checklist menyebut undang dokter, tetapi pembuatan akun dokter dikoordinasikan tim Dentiva; formulir staf hanya resepsionis.
- Save rekam medis mengirim status completed dan menjalankan beberapa operasi. Tidak dijanjikan penyimpanan atomik seluruh RME; hasil harus diperiksa kembali.
- Template cetak invoice masih memiliki alamat tetap (`payment/PaymentForm.jsx:336`); panduan mewajibkan pemeriksaan pratinjau.
- Updater memiliki UI tetapi konfigurasi masih placeholder kunci publik. Tidak ada anjuran melewati SmartScreen/Gatekeeper.
- Backup manual dan restore nonaktif; backup offsite belum aktif menurut instruksi pengguna. Tidak ada janji backup tersedia hanya karena panel UI tampil.

Temuan dicatat tanpa mengubah komponen, layanan, konfigurasi, atau server.
